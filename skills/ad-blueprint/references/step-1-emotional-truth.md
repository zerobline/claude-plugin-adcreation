# Step 1 — Clarify the Emotional Truth

**Codename: The Shame Scanner + Tension Architect**

Most brands fail here first: they start with features or benefits. Start with emotional bloodwork instead.

Purpose:

- Force radical clarity on what the audience *really* feels.
- Identify the shame, contradiction, or fear they won't post — but can't ignore.
- Extract a Spike Core so sharp it hurts to read (in a good way).

Before the headline, before the layout, before "pain points": excavate **one raw emotional truth** — the unspoken contradiction the audience is living in and hiding from. That is the **Spike Core**. If it doesn't sting, it doesn't sell.

## 1.1 The Shame Scanner — expose the hidden fear

Fill-in formula:

> They want to be seen as **[admirable image]**…
> But inside, they feel **[private emotion]**…
> And you can see it when they **[behavioural tell]**…

Example (creators):

> They want to be seen as visionary, driven creators…
> But inside, they feel like they're faking momentum…
> And you can see it when they over-design carousels instead of launching.

The behavioural tell carries most of the specificity. "Feel stressed" is a 2; "check Stripe every two hours like it's a pulse monitor" is a 5.

## 1.2 The Contradiction Stack — the Tension Architect

Build layered dualities that feel human, not market-researched:

1. "They want to **[aspiration]**, but hate how it makes them feel."
2. "They believe they're **[virtue]**, but fear they're actually **[shadow]**."
3. "They crave **[positive goal]**, but it's wrapped in **[buried emotion]**."

Example (founders): "They crave freedom, but it's wrapped in guilt for not doing enough."

## The Spike Meter

Rate every line. If it's not a 4 or 5, it dies.

| Trait | Ask | Score 1–5 |
|---|---|---|
| Specificity | Is it sharp, not vague? | |
| Emotional Hit | Do you feel a little exposed reading it? | |
| Self-Recognition | Would the audience say "that's me"? | |

Keep only Spike Cores that average **4+**.

Impact scale used across the method:

| Mark | Level | Feels like |
|---|---|---|
| 🔹 | Safe (1–2) | Mild empathy; could be a warm-up post |
| 🔸 | Stingy (3–4) | Reader nods, might pause |
| 🔴 | Diary-worthy (5) | Feels like a secret being exposed |

## Mastermind prompt

Write three truth lines using the Shame Scanner or the Contradiction Stack. Rate them. Keep only the one that stings the most. That becomes the **Emotional Spike Core** — the emotional engine for the ad.

## Common failure modes

- **Category language** ("busy professionals want efficiency") — no person talks like this. Rewrite as something they'd only admit to a close friend.
- **Insult instead of insight** — the line judges the audience rather than revealing them. Shift from "you're lazy" to the fear underneath.
- **No tell** — without an observable behaviour, the line stays abstract. Ask "what would I see them do at 11 p.m.?"
