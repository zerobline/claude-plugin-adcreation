# Privacy Policy — Mastermind Ad Engine

**Last updated: 24 October 2026**

This policy describes the Mastermind Ad Engine **skills-only** plugin published from [the zerobline repository](https://github.com/zerobline/claude-plugin-adcreation). The publisher is identified as **zerobline**. It covers the publisher's own processing, not OpenAI's or GitHub's services.

## What data is involved?

**Creative work in ChatGPT or Codex.** You may choose to provide text, advertising briefs, brand details, artwork, or other files to your OpenAI product to use the plugin. The present plugin is a set of instructions and reference files; it does **not** operate an independent server, require login, set publisher-operated cookies, or directly transmit those materials to the publisher. Your interaction is handled by the OpenAI product you use under its own privacy notice, settings and retention policies.

**Support and public repository.** If you voluntarily open a GitHub issue or pull request, GitHub and the repository maintainer can access the GitHub account name, issue text, attachments, comments, timestamps, and metadata that GitHub makes available. Do **not** post private client work, personal information, API keys or confidential artwork in a public issue.

## Why data is used

The publisher uses information voluntarily included in GitHub issues for bug diagnosis, compatibility troubleshooting, support responses and maintaining the open-source project. The plugin itself has no independent analytics, user profiling, behavioral tracking, ad network integration or data broker.

## Who receives data?

- **OpenAI:** handles content you provide in ChatGPT or Codex under the applicable OpenAI privacy terms and settings. This handling is not controlled by the publisher.
- **GitHub:** hosts the open-source repository and any issues or pull requests you choose to submit. GitHub's own data practices apply.
- **Publisher / repository maintainer:** can view the information you choose to share publicly on GitHub, for the purposes above.

The publisher does not sell data collected through this plugin. The plugin currently has no separate third-party service, advertising tracking or hosted MCP backend.

## Retention

The publisher does **not** maintain a separate store or log of ChatGPT/Codex prompts or uploaded artworks. Retention of content inside the OpenAI product is governed by OpenAI's controls and policies.

GitHub support submissions are publicly visible and may remain in GitHub's repository history or systems after closure. You can use GitHub's account and issue controls where available or ask the maintainer to review a specific public submission. The publisher cannot guarantee removal of copies, forks, search indexes or GitHub-hosted records.

## Choices and rights

You can choose not to open support issues. Do not include sensitive information in a public support request. For questions about content stored by OpenAI or GitHub, use those providers' privacy controls. For publisher-side questions, see [Support](https://github.com/zerobline/claude-plugin-adcreation/blob/main/SUPPORT.md) and open a GitHub issue **without including sensitive information**.

## Changes to this policy

If the plugin later introduces a hosted MCP endpoint, authentication, storage, telemetry, or additional data recipients, this policy must be updated before that capability is offered. Material changes will be reflected in this document and its update date.
